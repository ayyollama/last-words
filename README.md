# Last Words 🕯️ — obituaries for the living

Everything dies. Most things just haven't been told yet.

**Last Words** writes a eulogy for something that is *not dead yet* — a fax machine, an inbox-zero dream, a group chat on life support, or one of the three projects its author built and scrapped in a single day. Pick a patient, and an open-weight AI delivers its last words now, while it can still hear them. Día de los Muertos rules: you build the altar early.

## How it works
- One page, one button, one model call. No chat loop, no server, no API key.
- The orator is **Google's Gemma 3 (1B, instruction-tuned)** — an open-weight model — running **entirely in the visitor's browser** via Transformers.js. If Gemma can't load on a given machine, an open-weight understudy (Qwen2.5) performs, and the page says so honestly in the footer.
- Each eulogy follows the funeral structure: **The Life · The Legacy · Cause of Death** — the cause of death written in the future tense, because the patient is still alive. That's the joke, and the point.

## Why
Built for the **DEV Challenge — Ghost in the Machine (Hacktoberfest Week 4)**. The three patient-zero subjects at the top of the list — Séance, Debug Séance, and The Graveyard Shift — are real: they were built, tested, and scrapped by the author on October 30, 2026, in the search for an entry worth submitting. This is the one that survived, mostly because it does the least and means it the most.
